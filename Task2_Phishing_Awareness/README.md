# Phishing Awareness Training

An interactive online learning module built with HTML, CSS and JavaScript. No installation, API keys or backend required.

## Run
Download or clone this repository and open `index.html` in a browser. Internet is only needed to visit the external reference pages.

## Features
- Phishing, smishing, vishing, QR phishing and targeted attacks.
- Social engineering tactics and practical prevention habits.
- Click-to-reveal warning signs in a fictional email.
- Fake website and URL inspection guidance.
- Documented real-world scam patterns with FTC and NIST references.
- Eight-question quiz with explanations, progress, score and retry.
- Response guidance after clicking, entering credentials or running a file.
- Responsive layout and keyboard-accessible controls.

## Privacy
No credentials or personal details are collected. Quiz state stays in memory and resets on refresh. Fictional sample domains are reserved `.example` addresses and are not active links. External reference links are clearly labeled.
