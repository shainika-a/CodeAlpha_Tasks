# CodeAlpha Cybersecurity Internship

This repository contains the four tasks I completed during my CodeAlpha Cybersecurity Internship.

## Completed Tasks

1. **Network Packet Sniffer**  
   A Python program to capture network packets and display useful traffic information.

2. **Phishing Awareness Training**  
   An interactive learning module covering phishing attacks, warning signs, prevention tips, and quizzes.

3. **Secure Coding Review**  
   A security review identifying vulnerabilities in an application, with recommendations and corrected code.

4. **Network Intrusion Detection System**  
   A Suricata-based project for monitoring network traffic, detecting suspicious activity, and recording alerts.

## Repository Organization

Each task is organized in its own folder and includes the relevant code, supporting files, and a separate README with setup and execution instructions.
